---
title: "Function: clampScrollPixels"
description: "Clamps [pixels] into `[minScrollExtent, maxScrollExtent]`; pass  [allowOverscroll] to keep the measured value (2D viewports toggle this per  axis)."
---

Signature
```dart
double clampScrollPixels(double pixels, {required double minScrollExtent, required double maxScrollExtent, bool allowOverscroll = false});
```

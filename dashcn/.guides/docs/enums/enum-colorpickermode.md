```dart
/// Which colour space the picker's numeric fields and pad use: `hsl` drives
/// an HSL saturation/lightness pad, the others the HSV saturation/value pad.
enum ColorPickerMode {
  rgb,
  hsl,
  hsv,
  hex,
}
```

```dart
/// One component of a clock time.
///
/// Used to order and label the fields of a time picker; see [DatePart] for the
/// same idea applied to dates.
enum TimePart {
  /// The hour, 0-23.
  hour,
  /// The minute, 0-59.
  minute,
  /// The second, 0-59.
  second,
}
```

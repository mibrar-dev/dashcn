description: "Which channel(s) the slider drives."

```dart
/// Which channel(s) the slider drives.
///
/// `hue`, `sat`, `val`, `alpha` are single-channel bars; the rest are 2D pads.
enum HSVColorSliderType {
  hue,
  hueSat,
  hueVal,
  hueAlpha,
  sat,
  satVal,
  satAlpha,
  val,
  valAlpha,
  alpha,
}
```

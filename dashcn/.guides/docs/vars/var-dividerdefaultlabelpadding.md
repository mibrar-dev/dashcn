---
title: "Variable: dividerDefaultLabelPadding"
description: "Default padding around a divider label: upstream's separator label gutter,  8 logical pixels on both sides (upstream `px-2`), stored as density  multipliers and resolved by `Divider` against  `density."
---

Signature
```dart
const EdgeInsetsGeometry dividerDefaultLabelPadding = EdgeInsetsDensity.pxSymmetric(horizontal: 8);
```

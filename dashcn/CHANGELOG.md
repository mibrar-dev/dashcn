# Changelog

All notable changes to the `dashcn` package are documented here, following
[Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] - Unreleased

- Initial release as the `dashcn` package (renamed from `flutter_shadcn_kit`).
- Widgets-only design system: foundation, theme, primitives, components and
  blocks under `lib/src/`, with generated entry points (`lib/dashcn.dart`,
  `lib/foundation.dart`, `lib/theme.dart`, `lib/primitives.dart`,
  `lib/components/<id>.dart`, `lib/blocks/<id>.dart`).
- Runnable `example/` app.

# dashcn CLI reference snapshot (hand-maintained).
#
# The new CLI (P5, `dashcn_cli` branch `refactor/rearchitecture`) does
# not ship real `--help` text yet; this file is the documented command surface
# from rearch/reports/P5_CLI_PLAN.md §2 and MUST be re-pasted when the CLI
# lands. docs/tool/gen_docs_data.dart parses it into `kCliCommands`
# (docs_tables.dart); the CLI page renders each section's text plus a generated
# flags table. No other file hard-codes command syntax.
#
# Format contract (parser in docs/tool/src/readme_scan.dart):
#   * a section starts with a `$ <invocation>` line at column 0;
#   * the first `Usage:` line is the syntax string;
#   * flag lines match `      --flag=<value>  Description` (an optional
#     `-s, ` alias may precede the long flag);
#   * `#` lines are comments for this file and never reach the page.

$ dashcn --help
Component manager for the dashcn registry.

Usage: dashcn <command> [arguments]
-h, --help       Print this usage information.
    --version    Print the CLI version.

Available commands:
  init       Install the layer core and pick a theme preset.
  add        Add components and their dependency closure.
  remove     Remove registry-owned files (user-owned files stay).
  update     Pull upstream registry changes for installed files.
  list       List every component in the registry manifest.
  search     Search components by name, tag or description.
  info       Show dependency closure, files and theme class for one component.
  theme      List or apply theme presets.
  doctor     Check the install closure, lock drift and user-owned files.
  validate   Validate the registry manifest against the v2 schema.

Run "dashcn help <command>" for more information about a command.

$ dashcn init --help
Install the registry layer core (foundation + theme) into a project and choose
a theme preset. Writes .dashcn/config.json and dashcn.lock v2; installs no
component.

Usage: dashcn init [arguments]
-h, --help         Print this usage information.
    --dir=<path>   Install root (default: lib/ui/dashcn or the path recorded in .dashcn/config.json).
    --theme=<id>   Preset id from themes/index.json; interactive list when omitted.
    --yes          Accept defaults without prompting.
    --json         Print the result as JSON.

$ dashcn add --help
Add components and the transitive dependency closure (components -> primitives
-> foundation/theme). Existing user-owned files are never overwritten. Refuses
to install when a symbol would be defined twice (single-owner preflight).

Usage: dashcn add <ids...> [arguments]
-h, --help             Print this usage information.
    --dry-run          Print the plan without writing files.
    --json             Print the plan or result as JSON.
    --force            Continue past non-fatal preflight warnings.
    --all              Add every component in the registry manifest.
    --include-preview  Also copy preview.dart files (default: never).

$ dashcn update --help
Hash-based update of registry-owned files. Unchanged files are overwritten,
locally modified files are reported and skipped, user-owned files are never
touched. Regenerates theme/app_theme.dart from the locked preset.

Usage: dashcn update [ids...] [arguments]
-h, --help    Print this usage information.
    --all     Update every installed component.
    --check   Report only; exit 1 when anything is behind or modified.
    --json    Print the result as JSON.

$ dashcn remove --help
Remove registry-owned files for the given components. Refuses when another
installed component depends on the target.

Usage: dashcn remove [ids...] [arguments]
-h, --help               Print this usage information.
    --purge-user-themes  Also delete the user-owned *_theme.dart files.
    --json               Print the result as JSON.

$ dashcn list --help
List every component in the registry manifest.

Usage: dashcn list [arguments]
-h, --help    Print this usage information.
    --json    Print the list as JSON.

$ dashcn search --help
Search the registry manifest by component id, name, tag or description.

Usage: dashcn search <query> [arguments]
-h, --help    Print this usage information.
    --json    Print the matches as JSON.

$ dashcn info --help
Show the dependency closure, files, API symbols and theme class for one
component.

Usage: dashcn info <id> [arguments]
-h, --help    Print this usage information.
    --json    Print the report as JSON.

$ dashcn theme list --help
List the theme presets recorded in the registry manifest.

Usage: dashcn theme list [arguments]
-h, --help    Print this usage information.
    --json    Print the presets as JSON.

$ dashcn theme apply --help
Generate theme/app_theme.dart from a preset JSON (values-only file, full
rewrite; no regex patching). Updates the lock's theme section.

Usage: dashcn theme apply <preset> [arguments]
-h, --help      Print this usage information.
    --refresh   Re-read the preset JSON even when the lock hash matches.
    --json      Print the result as JSON.

$ dashcn doctor --help
Check the manifest, the installed closure, lock drift, user-owned files and
relative imports escaping the install root.

Usage: dashcn doctor [arguments]
-h, --help    Print this usage information.
    --json    Print the report as JSON.
Exit codes: 0 clean, 1 drift or modified files, 2 broken closure,
3 invalid manifest.

$ dashcn validate --help
Validate lib/src/manifests/registry.json against the v2 schema.

Usage: dashcn validate [arguments]
-h, --help    Print this usage information.
    --json    Print the validation report as JSON.

# P8-1 — dashcn package skeleton

Read first: `DASHCN_PACKAGE_PLAN.md` §1, §3, §4 (P8-1), `DASHCN_FEATURES_PLAN.md` §0, `$APP/pubspec.yaml`,
`$KIT/rearch/qa_gate.sh`, `$APP/tool/**`, `$DOCS/tool/sync_registry.sh`, `$DOCS/tool/gen_docs_data.dart`.

## Goal
`flutter_shadcn_kit/` becomes the publishable package `dashcn` 1.0.0 with `lib/src/` + generated public libraries,
an `example/` app, and every tool/gate updated for the new paths. **No public API renames** (that is P8-2) — only
package name, paths and import URIs.

## Steps
1. Moves (you MAY use `git mv` for these only, to keep history):
   - `$KIT/flutter_shadcn_kit` → `$KIT/dashcn`
   - `$KIT/dashcn/lib/registry` → `$KIT/dashcn/lib/src`
   - The runnable app parts (`lib/main.dart`, `android/ ios/ linux/ macos/ web/ windows/`) → `$KIT/dashcn/example/`
     (example is its own pubspec `dashcn_example`, `publish_to: none`, path dep on `dashcn`). Verify first what
     `lib/main.dart` and `lib/flutter_shadcn_kit.dart` contain; record in the report.
   - `flutter_cli_verification_example/`, `gen/`, `skills/`, `scripts/`, `dart_analyze_flutter_shadcn_kit.txt`: do NOT
     move/delete — list them in the report with a recommendation (keep / move under `tool/` / delete); orchestrator
     decides.
2. `pubspec.yaml`: `name: dashcn`, `version: 1.0.0`, description (60–180 chars, no "shadcn"), `homepage`,
   `repository: https://github.com/mibrar-dev/shadcn_flutter_kit` (repo rename pending), `issue_tracker`, `topics`
   (ui, design-system, widgets, components, theme), `platforms` (all six), `screenshots` → `brand/png/og-image.png`
   copied to `dashcn/doc/og-image.png`. Remove `cupertino_icons` if nothing in `lib/` uses it (verify). Keep the SDK
   floor comment, updated paths.
3. Rewrite every import URI `package:flutter_shadcn_kit/registry/…` → `package:dashcn/src/…` and relative paths that
   cross the move, across `$KIT/dashcn/{lib,test,tool,example}`, `$DOCS/{lib,test,tool}`, `$KIT/rearch/*.sh`,
   `$KIT/rearch/*.py`. Do it with a small Dart/analyzer-free string tool restricted to import/export/part directives and
   path literals; list every file touched.
4. Public libraries, generated by new `$KIT/dashcn/tool/gen_exports.dart` (`--check` exits 1 when stale):
   - `lib/dashcn.dart` (barrel: foundation + theme + primitives + all user-facing components; NOT blocks),
   - `lib/foundation.dart`, `lib/theme.dart`, `lib/primitives.dart`,
   - `lib/components/<id>.dart` per component, `lib/blocks/<id>.dart` per block,
   driven by `lib/src/manifests/registry.json` (verify actual manifest path/shape). Exports must not collide — resolve
   ambiguous exports with `show`/`hide` generated from the analyzer's declared names; report any real collisions.
   Remove `lib/flutter_shadcn_kit.dart` only if fully replaced (state it).
5. Update tools/gates for the new paths: `rearch/qa_gate.sh` (cd `dashcn`, `lib/src`, `test/registry` → keep test
   folder names as-is), `tool/rearch/check_*.dart` defaults, `$DOCS/tool/sync_registry.sh`, `$DOCS/tool/gen_docs_data.dart`
   source paths, `$DOCS/pubspec.yaml` path dependency (if any) → `../dashcn`. Add `gen_exports --check` to qa_gate.
6. Package hygiene: `README.md` (short: what, install `flutter pub add dashcn`, minimal `DashcnApp` example — note the
   name lands in P8-2, so write the current class name and add `<!-- P8-2 -->` markers), `CHANGELOG.md`
   (`## [1.0.0] - Unreleased`), `LICENSE` (copy repo licence — verify `$KIT/license.md`), `example/README.md`,
   `.pubignore` (exclude tests' goldens/screens, tool output, rearch artifacts).
7. `dart pub publish --dry-run` in `$KIT/dashcn`: zero errors; list warnings in the report.

## Owns
Everything under `$KIT/dashcn/**` (after the move), `$KIT/rearch/qa_gate.sh`, `$KIT/rearch/*.sh|*.py` path edits,
`$DOCS/tool/**`, `$DOCS/pubspec.yaml` (dependency path only), `$DOCS/lib/**` + `$DOCS/test/**` import-URI edits only.

## Gates (all must pass; paste final lines)
`rearch/qa_gate.sh` · `dart run tool/gen_exports.dart --check` · `flutter analyze` in `$KIT/dashcn` and `example/` ·
`$DOCS`: `dart format --output=none --set-exit-if-changed lib test tool`, `flutter analyze`, `flutter test`,
`dart run tool/gen_docs_data.dart --check`, `bash tool/sync_registry.sh --check` · `dart pub publish --dry-run`.

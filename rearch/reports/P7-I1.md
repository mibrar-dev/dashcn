# P7-I1 — Picker trigger icon alignment + content-sized width

## Root cause (verified in code, no PNGs opened)

- `primitives/form_core/object_form_field.dart` wrapped `leading`/`trailing`
  in `SizedBox(height: 0, child: Center(...))` (`_adornment`) and the label in
  `Flexible` inside an inner `Expanded` row. In widget tests (Ahem) the box
  centres coincide, but on web (Geist, the docs font) the glyph visual centre
  sits ~6–8px above the box centre, so the 16px calendar/clock icon paints
  below the label. Font-dependent, not layout-dependent.
- Width used hard minima (`triggerMinWidth` 240 date / 140 time, scaled) plus
  `Flexible`/`Expanded`, so short triggers were forced wide and long labels
  could wrap/ellipsize instead of hugging.

## What changed (registry-owned only)

- `primitives/form_core/object_form_field.dart`:
  - Removed `triggerMinWidth` (clean break, no alias).
  - `_adornment` is now a fixed `SizedBox.square(16)` + `Center` (shadcn
    `size-4`); one `Row(min, center)` holds icon + gap + label, so both share
    one centre in every font and the icon can never push the trigger past h-9.
  - Removed `Flexible`/`Expanded` and the outer `Row(Expanded)`; the
    `Clickable` child is the content row directly. Never an ellipsis here.
  - Hug via `IntrinsicWidth` always (empty placeholder sets the width);
    `expand` or a tight parent fills (`SizedBox(inf)` / tight forces width).
    A tight parent narrower than the label clips with a Flutter overflow
    (debug stripes) — never wrap/scroll/ellipsis.
- `components/date_picker/date_picker.dart` (`DatePicker`, `DateRangePicker`):
  removed `triggerMinWidth: 240`; default + value labels are now explicit
  single-line `Text(softWrap: false, maxLines: 1, overflow: visible)`;
  doc updated to hug/`icon + gap + full label + padding`.
- `components/time_picker/time_picker.dart` (`TimePicker`, `DurationPicker`):
  same — removed `triggerMinWidth: 140`, single-line labels, doc updated.
- `date_picker/README.md`, `time_picker/README.md`: hug contract, no minima.
- `test/registry/components/p7f2_input_widths_test.dart`: updated to the new
  contract (hug <300/>100, tight 300 fills, time hug, long-label growth).
- `test/registry/components/p7i1_trigger_alignment_test.dart` (new, 26 tests):
  centres ±1px + 16px icon box + no-ellipsis for date/range-long/time across
  compact/default/spacious × light/dark with GeistSans + Lucide loaded
  (docs web font); width hugs short/long; tight 800 fills, tight 200 reports
  overflow.
- Audited, no edits: `filter_bar` (`FilterBarDateControl` 180×36 tight fills,
  same as before), `date/time/object` previews (no fixed widths),
  `studio_tabs.dart` / `collage_home_time.dart` range/time cards (stretch
  columns fill). Left for P7-H1/P7-C2 per brief.

## Measured (Ahem unless noted; Geist loaded for alignment)

- Empty date trigger hugs to 204px (was 266 with the 240 min); long range
  `January 1, 2026 - January 14, 2026` shows in full and is wider than empty,
  still <1000 (hug, not parent-wide).
- Icon/label `dy` diff ≤1.0px in all 24 matrix cases (Geist loaded).
- No `TextOverflow.ellipsis` in any trigger subtree.
- Height preserved: `date_picker_test` 19/19 pass; P7-F3 height match held
  until the concurrent breakage below (see Gates).

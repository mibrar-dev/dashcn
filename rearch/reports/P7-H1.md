## Changes (repo files)

Registry:

- `flutter_shadcn_kit/lib/registry/components/text_area/text_area.dart`
  - New optional `textInputAction` passthrough to `Input` (default null, so
    the old "Enter inserts newline" behaviour is unchanged). A chat composer
    sets `TextInputAction.send` so Enter submits. `TextArea` previously had
    no way to request a send action.
- `flutter_shadcn_kit/lib/registry/components/chat/preview.dart`
  - New `Live` example: working thread (send → bubble, 800 ms → typing dots,
    +700 ms → canned reply cycling 3 answers, auto-scroll via `jumpTo`,
    Send `enabled` follows non-empty input). Composer is
    `TextArea(minLines: 1, maxLines: 4, textInputAction: send)`. Static dots
    (no ticker) so ticker-off stages stay still. Fits the 720x420 stage.
- `flutter_shadcn_kit/lib/registry/blocks/calendar-01/calendar_01.dart`
  - Two-month threshold `>= 720` → `>= 600` on the INSIDE-constraint width.
    Root cause: the card caps at 720 and its own padding leaves 688 inside,
    so `>= 720` could never hold — one month rendered left, right half
    empty. Two nominal grids need ~568 px (2 × 272 incl. p-3 shell + 24 gap).
  - Footer now shows the picked range first:
    `Oct 12–18, 2026 · 6 nights`, `Oct 30 – Nov 2, 2026 · 3 nights`,
    same-day `Oct 12, 2026 · Same-day stay`, single
    `Oct 12 — tap another day to extend the range`. Clear/Apply were already
    wired and are now covered by test.
- `flutter_shadcn_kit/lib/registry/blocks/dashboard-01/dashboard_01_table.dart`
  + `dashboard-01/meta.json`
  - Deleted the bespoke `_Dashboard01Pill` `Container` (painted the full
    column width, too tall). Status cell is now
    `Align(centerStart, Badge(variant))`: Paid → primary, Pending →
    secondary, Refunded → outline. Badge defaults are exactly shadcn badge
    (h-5/px-2/text-xs, ~20 px tall, ~46 px wide for "Pending").
  - `defaultRowHeight: FixedTableSize(48)` → `40` (shadcn `TableHead` h-10;
    body content maxes at ~37 px incl. borders, so 40 centres evenly).
  - meta.json `components` deps gain `badge` (generator-derived).

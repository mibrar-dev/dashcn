## Honesty notes

- Null is always Not measured (outline badge), never Pass. No component is
  currently unmeasured (83/83 harness markers), but unknown ids render all
  Not measured.
- Frame title is exactly `Frame build time — test environment (relative)`
  with both a hover `Tooltip` and inline text stating relative numbers, not
  device performance.
- Tap-target rows carry `Mobile tap-target guideline (44/48 px) —
  informational for desktop-sized controls, not hidden`.
- RTL `mirrored: null` renders as Symmetric (message contains symmetric) or
  Not applicable (no ltrX/rtlX), never as Not measured unless `passed` is
  null. `avatar`/`divider`/`spinner` (null/null) show Not applicable.
- Tests show count + harness pass (`passed: true` Pass, else Not measured);
  never registry pass.

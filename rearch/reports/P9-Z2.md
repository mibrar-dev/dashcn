## 1. Generator: `docs_starters.dart` from `starter.json` + README

New tool files:

- `docs/tool/src/starter_scan.dart` — `StarterFacts` (+ route/file facts),
  `scanStarters(root, startersJson)` ordered by id. Validates like the kit
  manifest builder (`type: starter`, name/description, `themePreset`
  non-empty, platforms non-empty subset of the six, routes
  `path/title/kind/flow|block|page`, files `template/target` under
  `lib/|test/`, tags sorted, `install`). Re-checks the filesystem:
  `starters/<id>/starter.json` + non-empty `README.md` + every template
  exists — a stale manifest fails `--check` here too.
- `docs/tool/src/render_starters.dart` — renders `lib/generated/
  docs_starters.dart` (`DocsStarter`, `DocsStarterRoute`, `DocsStarterFile`,
  `kStarters` ordered by id). Banner sources are the registry manifest plus
  `starters/<id>/starter.json` + `README.md`. Only rendered-template
  **targets** are emitted, never raw `.tmpl` text (pages link to GitHub).
- Wiring: `registry_scan.dart` gains `RegistryScan.starters` (parsed from
  manifest `starters`); `model_build.dart` adds the `docs_starters.dart`
  bundle entry + `starters: 3` in `describeModel`; `gen_docs_data.dart`
  exports the new modules.

`dart run tool/gen_docs_data.dart` now reports `starters: 3` and
`--check` covers **18 files** (was 17). Mirror sync unchanged: starters ship
no `.dart` (templates are `.tmpl` + `.json`/`.md`), and the pages show the
file list only — per the brief, no mirror change is needed when no template
sources are shown.

Generator tests (`tool/gen_docs_data_test.dart`, new `starters catalog`
group, 3 tests): 3 starters ordered `chat, saas, shop` with routes/files,
scan-vs-manifest equality per starter, search-index coverage (starter kind
count == starters count, `saas` keyword, index page present).

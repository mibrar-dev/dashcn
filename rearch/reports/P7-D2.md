# P7-D2 — preview canvas: soft dotted pattern, separated surfaces

## What changed

The component preview canvas keeps its dot-grid pattern but renders it soft,
and component surfaces now always differ from their backdrop.

### `docs/lib/widgets/preview_stage.dart` (only hand-edited lib file)

- **Canvas fill** (was `colors.background`): new `previewCanvasColor(colors)`
  = muted nudged 8% toward foreground
  (`Color.alphaBlend(fg @ 8%, muted)`). Plain `background` equals the
  card/popover surface in several presets (neutral light, vercel, …), which is
  why previews blended in; plain `muted` still collides elsewhere (vercel,
  mono-dark popover). The 8% nudge was chosen by surveying all 43 registry
  presets × light/dark × card/popover (script in §Measured): it maximizes the
  worst-case contrast (min 1.026 at claude-dark card; t=0.05/0.06/0.10 all
  collide somewhere at ≤1.014).
- **Dots** (were border @ 45%, hard 1 px): new public `PreviewDotGridPainter`
  draws from the **foreground** token at 8% (light) / 10% (dark)
  (`previewDotColor`, within the brief's 6–10% / 8–12%), on the same 20 px
  grid with the same 1 px radius, with a radial fade (15% strength at the
  centre → full past 80% toward the corners, smoothstep) so the component
  sits in a calm spot. Dots batch into 8 alpha buckets via
  `Canvas.drawPoints`: one loop + 8 draw calls per repaint.
- **Blur on the pattern layer only**: the pattern is
  `Positioned.fill(RepaintBoundary(ImageFiltered(σ=1.5, CustomPaint)))`
  *under* opaque content — content is a sibling, never filtered. The
  `RepaintBoundary` + `isComplex: true` / `willChange: false` cache the
  blurred raster; scrolling or animating previews never re-runs the blur.
  σ=1.5 turns 1 px dots into a soft whisper (measured edge-dot peak ≈ 3 LSB
  per channel, §Measured) without erasing the texture.
- **Layout preserved**: the content stays a *non-positioned* `Stack` child so
  it keeps sizing the stage (a `Stack` requires bounded constraints, which the
  page scrollable does not give), with `Stack(alignment: center)` re-centring
  it horizontally. Two regressions caught by existing tests on the way there,
  both fixed (see §Notable findings).

### `docs/test/preview_canvas_test.dart` (new, 13 tests)

- Canvas ≠ card/popover/background + WCAG contrast ≥ 1.02 vs card/popover for
  neutral + claude × light/dark (measured worst is 1.026 — threshold holds
  with margin; full-preset survey in §Measured).
- Dot alpha in 6–10% (light) / 8–12% (dark) for neutral + claude.
- Structure: exactly one `ImageFiltered`; it wraps the dot `CustomPaint` and
  contains no content; stage fill is the canvas colour; `pattern: false`
  renders no blur layer.
- Perf contract: pattern behind a `RepaintBoundary`, static paint flags,
  `shouldRepaint` false for same/equal colours.
- Pixels (rasterised 400×300 neutral stage, both modes): centre pixel is the
  card surface exactly (content unblurred); dot-free corner pixel is the
  canvas fill (±4 LSB); edge dot pixel (10,10) differs from canvas by 1–12
  LSB total — soft but present.

### Blocks viewport: unchanged (deliberate)

`widgets/block_viewport.dart` paints plain `background` with no dot grid, and
blocks are full-bleed pages that paint their own `background` over it — a
pattern layer there would be invisible. The letterbox ring around
tablet/mobile frames stays `background`. No change, no test impact
(`blocks_pages_test.dart` "preview viewport uses the background token" still
passes). The login-02 panel's internal `_DotPainter` is block design, not
preview canvas — untouched.

## Notable findings

1. **`RenderStack` loosens non-positioned children**: first cut put content as
   a bare `Stack` child → it shrink-wrapped and pinned top-start (D1b
   centring test: 117 px off). Fixed with `Stack(alignment: center)`.
2. **`Stack` requires bounded constraints**: second cut (`Positioned.fill`
   content) threw "A Stack requires bounded constraints" on real pages (the
   scrollable gives unbounded height; the sweep caught it, unit tests did
   not). Final shape — content non-positioned (sizes the stage) + pattern
   `Positioned.fill` (laid out after sizing) — satisfies both.
3. **No single tint is perfect**: pure muted collides (vercel, mono-dark);
   5–6% foreground tints collide (doom-64-light, claymorphism-d analogues);
   8% maximizes the global minimum. The residual worst case (claude-dark
   card, 1.026) is inherent in that preset's near-identical bg/card tokens.
4. **Concurrent agent**: P7-G1's uncommitted gooey_toast/primitive edits were
   in the tree throughout. I regenerated `docs_example_sources.dart` +
   `docs_previews.dart` (they follow the gooey preview source); if P7-G1
   edits further, codegen goes stale again and they re-run. I touched no
   toast/block/registry files.

# P7-F2 — Date/time/object/formatted/phone inputs hug their content (user report 2026-10-11)

## Verdict on the suspected root causes

1. **Trigger stretch + flush label — confirmed, two root causes in
   `primitives/form_core/object_form_field.dart`.** (a) The trigger padding
   resolved `widget.popoverPadding ?? objectFormPromptPadding`: both pickers
   pass `popoverPadding: EdgeInsets.zero` (meant for the popover surface), so
   the *trigger* painted zero padding and the label sat flush against the
   border. The trigger now always paints `objectFormPromptPadding`
   (`px-3 py-2`, density-scaled). (b) The trigger had no intrinsic sizing, so
   it stretched to the parent (~560px in the report). It is now wrapped in
   `IntrinsicWidth` (the same pattern `Select` uses), with `expand: false`
   by default and a density-scaled `triggerMinWidth`. A tight parent (a
   stretched form column) still fills; a tight parent narrower than the
   minimum drops the minimum instead of overflowing (verified: 200px-tight
   date trigger renders 200 wide, no exception).
2. **Icon on the wrong side — confirmed.** Both pickers passed the calendar /
   clock icon as `trailing`. shadcn's date trigger is `w-[240px]
   justify-start` with the icon leading. Both pickers (plus `DurationPicker`)
   now pass the icon as `leading` (16px, muted), label left-aligned;
   `DatePicker`/`DateRangePicker` get `triggerMinWidth: 240`, `TimePicker`/
   `DurationPicker` 140. New `expand` flag on all four for full-width fields.
3. **Object uneven spacing + empty right area — confirmed, fixed widths.**
   `date/time/durationSegmentRungs` passed fixed `width: 40/60` overrides,
   which (since P7-F1) act as minimums and left dead space inside the
   narrower boxes. Widths are now null (measured from the text style), and
   the object previews dropped their `SizedBox(280)` wrappers, so the field
   hugs segments + separators with the trailing prompt button at the end.
4. **Formatted separators in the wrong places — the *shape* was misdeclared,
   not the renderer.** The renderer lays parts out in declared order
   (covered by a new order test). The phone preview declared
   `[3][' ('][3][') '][4]` which renders `555 (123) 4567`; it now declares
   `['('][3][') '][3]['-'][4]` = `(555) 123-4567`, matching its own doc
   comment, the README snippet and the component doc example. Preview
   `SizedBox(300)` wrappers removed (they caused the empty trailing area);
   the field hugs in loose parents and fills tight ones (both tested).
5. **Phone two loose boxes — confirmed, now one joined group.**
   `PhoneInput` renders a single shared-border container (fill/border resolve
   per brightness, hover included via `MouseRegion`) holding a borderless
   country `Select` (ghost variant + transparent trigger override), a 1px
   divider (`input` token, keyed `shadcn.phone_input.divider`) and a
   borderless number `Input` (`decoration: BoxDecoration()`). The row still
   hugs (`Row(min)`); measured 391px loose with defaults (180 + 200 +
   divider/margins + borders). Existing size tests (180/200/36) still pass
   unchanged. `fieldGap` now pads the divider (half each side).

## What changed

- `primitives/form_core/object_form_field.dart`: `expand` (default false) +
  `triggerMinWidth` params; trigger padding always the prompt padding;
  `IntrinsicWidth` hug / `SizedBox(inf)` expand / tight-narrow fallback via
  `LayoutBuilder`.
- `components/date_picker/date_picker.dart`: `expand` on both pickers;
  leading 16px muted icon; `triggerMinWidth: 240`.
- `components/time_picker/time_picker.dart`: `expand` on both pickers;

  joined group as above; `_groupSelectTheme` const; divider key.

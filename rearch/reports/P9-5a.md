Status: done (pending orchestrator QA). Branch `refactor/dashcn`.

## What was built

Harness `dashcn/test/scorecards/scorecard_harness_test.dart` (generated,
checked in, 338 lines): for each of the 83 listed components it pumps the
canonical example (first docs preview via `examples/<id>.dart`) under
`Theme(const ThemeData())` + `Directionality` + `Overlay.wrap` + 800x600
stage, with `pump()` + `pump(500ms)` only (never `pumpAndSettle`), per-test
`Timeout(60s)`, and records via `stdout.writeln('SCORECARD {...}')`:

- a11y: `textContrastGuideline`, `labeledTapTargetGuideline`,
  `androidTapTargetGuideline`, `iOSTapTargetGuideline` via
  `guideline.evaluate(tester)` (with `ensureSemantics`), plus semantics
  present (any node with label/value/hint/tooltip, traversed from
  `renderViews` like the guidelines do);
- rtl: pumped under `Directionality(rtl)`, no exception/overflow via
  `takeException`, leading-edge mirrored by comparing first-`Text` x in LTR
  vs RTL (`mirrored: true` when shift > 1px, else null with
  `symmetric layout` message; `passed` = renders);
- frames: 120 x `pump(16ms)` with `Stopwatch` around each, p50/p90 ms,
  label exactly `test environment (relative)`;
- output: one JSON line per component, `printOnFailure`-free.

Examples `dashcn/test/scorecards/examples/<id>.dart` (83 files, 8 lines
each): `Widget scorecardExample(BuildContext) => <camel>Previews[0].builder`
(kit only, no material). Variable names discovered with `package:analyzer`
(`parseString`, unresolved AST), never regex.

Tool `dashcn/tool/gen_scorecards.dart` (400 lines): discovers listed ids
from `lib/src/components` + `meta.json`, preview vars via analyzer,
writes examples + formatted harness, runs
`flutter test test/scorecards --reporter json`, collects markers (both JSON
`print` events and raw `Shell: SCORECARD` lines), counts tests per component
via analyzer (`test`/`testWidgets`/`testGoldens` in
`test/registry/components/<id>_*` or folder plus `tags: component:<id>` in
other files), writes `lib/src/manifests/scorecards.json`
(`generatedAt`, `commit`, `flutter`, `components: {id: {a11y, rtl, frames,
tests}}`, null = not measured). `--check` compares harness bytes and JSON
excluding `generatedAt`/`commit`/frame numbers, exits 1 when stale.
`--harness-only` regenerates examples + harness without running tests.

Shared pure logic `dashcn/test/scorecards/scorecard_model.dart` (308 lines,
imported by the tool): `TestVisitor`, counting, `parseScorecardOutput`,
`buildScorecards`, `scorecardsEqual`, `readCommit`, `readFlutterVersion`,
`runScorecardTests`.

Tests `dashcn/test/scorecards/gen_scorecards_test.dart` (225 lines, 11
tests): parsing (JSON events, shell lines, duplicates), aggregation
(null = not measured, label verbatim), equality (ignores timestamp/commit/
p50/p90, detects a11y/rtl/count changes), counting (analyzer, prefix +
tags via temp dirs), harness generation (no `pumpAndSettle`, timeout,
label, SCORECARD).

Manifest `dashcn/lib/src/manifests/scorecards.json` (83 components, 214K):
`generatedAt` UTC ISO, `commit` from `git rev-parse HEAD`, `flutter`
`3.47.7 / Dart 3.13.5`. Full harness run: 83/83 markers collected, 0 missing.

# P7-C2 — every preview must be a working, interactive demo (sweep)

**Brief:** P7-C2 (sweep of every *listed* component's `preview.dart`)
**Date:** 2026-10-11
**Owner (this sub-agent):** 70 listed components (118 total − 35 hidden building blocks −
5 P7-C1 components − 6 P7-F1/F2/F3 input components)
**Scope excluded (other agents live there):** `chip`, `carousel`, `pinned_sheet`, `tree`,
`breadcrumb` (P7-C1) and `formatted_input`, `object_input`, `date_picker`, `time_picker`,
`phone_input`, `gooey_toast` (P7-F1/F2/F3).

## Method

1. Scanned all 70 in-scope `preview.dart` files for static-demo signals: callbacks absent or
   empty (`onPressed: () {}` / `onChanged: null` / a `_noop`/`_ignore` top-level function),
   `const` widget trees that nothing can change, overlay surfaces with no trigger, values
   hard-coded so no gesture can alter them, and developer placeholder labels.
2. Checked each component's own widget source to decide *where* the fix belongs: a demo that
   is dead because the preview passes no state gets local state (preview fix); a demo that is
   dead because the component has no way to report a gesture gets a minimal additive root
   change (component fix).
3. Re-read the preview under the P6-F3 contract (shrink-wrap inside 720×420 / 375, theme from
   `ShadcnTheme.of(context)`, state inside the example's own `StatefulWidget`).

Legend: ✅ fixed · ⬜ not a bug / no change · 🟡 documented limitation (component is
presentational — verified in source)

## Deliberate decisions

1. **`preview.dart` imports do not need `meta.json` deps.** The installer copies `preview.dart`
   only with `--include-preview` (`cli .../installer_plan_part.dart:33`), and
   `check_layers` skips it (`layer_checks.dart:280,298`). The only component-file-level
   import I added is `table.dart` → `primitives/clickable.dart`, and that one *is* declared.
2. **The press counter for single buttons lives in the button label**, not in a caption
   below it: the docs gate asserts the Button example is centred on both axes
   (`docs/test/component_examples_test.dart:205`), and a caption would push it 10 px off
   centre. Row examples (`Sizes`, `With icon`) keep the shared status line below.
3. **`steps` stays presentational.** Making it advance would need a new public API
   (`currentStep` + callback) — a feature, not a sweep fix. Documented above instead.

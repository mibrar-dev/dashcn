## 1. Docs block viewport (`docs/lib/widgets/block_viewport.dart`)

Replaced the P7-B1 intrinsic-height frame with fixed page frames, like the
reference iframe:

- `BlockViewport` is now a real page size: desktop **1280×800**, tablet
  **768×1024**, mobile **390×844** (was: fill/768/375, height intrinsic,
  min 360).
- The block always gets **tight page constraints** (full width + full
  height), so splits fill halves edge to edge and sidebars run full height.
  Blocks may now use vertical `Expanded` (bounded host only; every rewritten
  block keeps an unbounded fallback so it never throws).
- The page is **scaled down to fit** when the card is narrower (uniform
  `FittedBox.contain` on a tight output box — text included, like an iframe
  zoom), never upscaled; wider cards centre the page. Desktop paints no inner
  border (the card border is the single frame); tablet/mobile keep their
  bordered device frames.
- `/blocks/<id>` ("Open in new tab") reuses the same frame, so its desktop
  preview IS the full-window 1280×800 page. No separate chromeless route was
  added (see open questions).
- `kBlockPreviewMinHeight` (360) is kept as a compat constant; nothing reads
  it anymore.

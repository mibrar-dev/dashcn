## 1. Trigger fix (root)

`flutter_shadcn_kit/lib/registry/primitives/form_core/object_form_field.dart`:

- Restored `Flexible` around the label in the trigger `Row` (P7-I1 had
  removed all flex to hug long labels). Hug is preserved: `Row`'s max
  intrinsic width counts flex children at full width, so `IntrinsicWidth`
  still sizes to `icon + gap + full label + padding` in a roomy parent;
  in a narrower parent the label shrinks to the available width and wraps
  to a second line instead of throwing. The 16px icon box, the single
  centred row, and the never-ellipsis contract are untouched.
- Border-box padding (`_triggerPadding`): `Container`/`AnimatedContainer`
  insets its child by the decoration border widths (verified in the Flutter
  SDK source, `container.dart` `_paddingIncludingDecoration`), so the
  painted padding was spec + 1px per side and the trigger measured 38px at
  the spacious density (`20 pad + 2 border + 16 row`) while `Input` stays 36
  (`20 + 2 + 14`). The resolved `px-3 py-2` padding is now deflated by the
  1px trigger border (`_triggerBorderWidth`, shared with the `Border.all`),
  so the painted padding is exactly the spec and the total stays h-9 at
  every density. Same philosophy as the button size table's `insetBorder`.
  Trigger width narrows by 2px; every width test uses range assertions.

`components/date_picker/date_picker.dart`, `components/time_picker/
time_picker.dart`: all 8 trigger labels went from
`softWrap: false, maxLines: 1` to `maxLines: 2, overflow: visible`
(still never an ellipsis). Max intrinsic width is unchanged (single-line
layout at infinite width), so hug sizes are identical; narrow parents wrap
to 2 lines. Doc comments + both READMEs updated to the wrap contract.

`test/registry/components/p7i1_trigger_alignment_test.dart`: only the last
test changed — `tight parent fills; narrow reports overflow, not wrap` is
now `tight parent fills; narrow wraps, never overflows` (width 200, no
exception, label 2 lines, still no ellipsis). All 24 alignment tests
(icon centred ±1px, 16px box, no ellipsis, hug widths) untouched and green.

## 2. Button fix (root)

`components/button/button_status_content.dart`: the statusful row is now
`[slot, gap, Flexible(label), trailing?]`. Roomy layouts are pixel-identical
(max intrinsic = full label; P7-S1's 35 widget + 6 controller tests all
green, incl. width stability). Narrow parents shrink the label instead of
throwing the 12px `RenderFlex` overflow seen on `/docs/components/button`
at 320px. Wrap (not ellipsis): labels are caller-owned widgets and only
wrap is enforceable at this layer; shadcn CSS would paint outside here, so
wrap is strictly safer. README documents it.

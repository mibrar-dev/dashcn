Button

Triggers an action. Six variants, four sizes, loading and icon states — every visual a theme token, AA on all 42 presets.

iphone.dart — same widget

Button(
  variant: ButtonVariant.default,
  size: ButtonSize.default,
  child: Text('Save'),
)

Install

Copies button.dart plus its tokens into your project. You own the file after that.

flutter_shadcn add button

Usage

import 'package:plinth/button.dart';

Button(
  variant: ButtonVariant.outline,
  size: ButtonSize.sm,
  onPressed: () => save(),
  child: Text('Save'),
)

## The CLI commands

`dashcn_cli` lives in a separate repo (`mibrar-dev/dashcn_cli`), so this
worktree ships the kit side plus a reference implementation the CLI wraps.
Two installer designs currently coexist in the tree (parallel sessions —
converge on one before the `dashcn_cli` companion PR):

- `dart run tool/locale.dart` (tested, `test/tool/locale_tool_test.dart`,
  7 tests): `list [--json]` prints code/direction/key counts;
  `add <code> [--dir <project-dir>]` writes
  `<dir>/dashcn_locales/dashcn_locale_<code>.dart` (complete standalone
  `ComponentLocalizations` subclass resolved from
  `lib/src/manifests/locale_tables.json`, `_number` helper included) and
  refreshes `<dir>/dashcn_locales/dashcn_locales.dart`
  (`dashcnLocalesDelegate`, `dashcnSupportedLocales`). Offline, no pasting,
  idempotent re-add; the generated project files pass `dart analyze`.
- `dart run tool/src/locale_tool.dart`'s library (untested): wiring-only
  alternative — `add` writes `<dir>/lib/dashcn_i18n.dart`
  (`kDashcnLocales` + `dashcnLocaleDelegates()`) reusing the kit's built-in
  tables, recording the choice in `<dir>/dashcn_locales.json`.
- Mapping for the `dashcn_cli` companion PR: `dashcn locale add <code>` ≡
  `tool/locale.dart add` against the vendored `locale_tables.json`;
  `dashcn locale list` ≡ `tool/locale.dart list [--json]`.

## RTL decisions

- A locale implies its direction: `isRtlLocale`/`textDirectionForLocale`
  (CLDR set: ar he fa ur ps yi ug sd ku); `DashcnApp` resolves
  `Directionality` from the locale via `GlobalWidgetsLocalizations`.
- Mirrored: breadcrumb separator, date-picker header chevrons, pagination
  prev/next chevrons, feature-carousel arrows, carousel swipe/keyboard
  deltas (pre-existing). New: `DashcnDirectionalIcon`
  (forward/backward chevron pair) and `DashcnLtr` (numbers/code guard).
- Numbers, durations, file sizes, code and diff porcelain stay LTR and
  untranslated (digits, `B/KB/MiB`, `HH:MM:SS`, `1d 2h`, `---`/`+++`,
  `rename from/to`, git status words). Country names stay English proper
  nouns (CLDR data); the phone-input search chrome is localized. Key-cap
  labels (Ctrl/Shift/Alt/Esc) stay platform-conventional.
- Tests: `i18n_rtl_test.dart` (10 tests: direction mapping, DashcnApp
  resolution, ar/en chevron mirroring at 375 px, LTR digits in RTL, de/ar
  date-picker + de dialog at 375 px, per-instance override) and the 12
  committed captures (`captures/`, `CAPTURES.md`).
